PyXtal: A Python library for crystal structure generation and symmetry analysis

Scott Fredericks, Kevin Parrish, Dean Sayre, Qiang Zhu · Computer Physics Communications (2020) · 142 citations · doi:10.1016/j.cpc.2020.107810 confidence: high ⚠ verification flagged claims
> PyXtal is an open-source Python library for generating random symmetric structures for atomic and molecular systems across all dimensionalities (0D clusters, 1D rods, 2D layers, 3D crystals). Given a symmetry group, stoichiometry, and volume, it automatically selects compatible Wyckoff positions using a step-wise merging scheme, and for molecules it detects point-group symmetry to place them into special Wyckoff positions with valid orientations, enabling arbitrary Z'. It also supports symmetry-preserving structure modulation via asymmetric-unit perturbation and group-subgroup transitions, plus utilities for symmetry analysis, geometry optimization, and simulated powder XRD. Benchmarks on Lennard-Jones clusters and carbon/silicon allotropes demonstrate that pre-symmetrized trial structures improve the success rate of finding low-energy configurations. Contribution

A standalone, free Python package that generates symmetric trial structures for 0D-3D atomic and molecular systems, uniquely supporting molecules in special Wyckoff positions with arbitrary Z' (fractional to multiple integers) and low-dimensional (point/rod/layer group) systems that prior tools (Randspg, Genarris) did not cover together.

Method

Structure generation flowchart: user inputs dimension, symmetry group, stoichiometry, volume; a Wyckoff compatibility check iterates through WP combinations; lattice generation using Gaussian-sampled shear matrices with constraints per crystal system (and spheres/ellipsoids for 0D clusters); WP insertion from highest to lowest multiplicity with a merging scheme following the USPEX-style approach (Ref 9/14); distance checking against covalent bond lengths using a 3x3x3 supercell approximation (lattices constrained to angles 30-150 degrees). For molecules, point group is detected via Pymatgen PointGroupAnalyzer and valid orientations aligning molecular symmetry axes with Wyckoff site symmetry are enumerated. Chiral inversion is disabled by default. Structure modulation via asymmetric-unit perturbation (including molecular reorientation and dihedral rotors) and group-subgroup transitions using Bilbao/International Tables symmetry relations. Dependencies: NumPy, SciPy, Pandas, Pymatgen, Spglib, optional Openbabel and ASE.

Key results

- LJ38 clusters: ground state found 278 times per 10,000 with random pre-symmetrization vs 0 without - LJ55 clusters: ground state found 73 times per 10,000 with pre-symmetrization vs 0 without - LJ75 clusters: ground state found 1 time per 10,000 with pre-symmetrization vs 0 without; 20,000 structures generated per size (10,000 symmetric, 10,000 random) using 56 built-in point groups, optimized with SciPy conjugate gradient - Pre-symmetrization spans structure space more effectively (higher average energy) while purely random structures cluster in a narrow energy range - For carbon (5000 structures, 2/4/6/8/16 atoms per cell, random space groups 2-230, PBE-GGA in VASP, 600 eV cutoff, 0.15 K-spacing): diamond and graphite found frequently, plus lonsdaleite and sp3/graphite-like variants; for silicon: cubic diamond ground state found in each run - Energy landscape is narrower for size-2 primitive cells; beyond ~4 atoms the number of atoms in the primitive cell has little influence on energy distribution - XRD similarity example between Fd-3m and I41/amd subgroup structures reported as 0.983114

Limitations

- PyXtal is not a complete CSP package; it only generates trial structures and must be interfaced with external prediction codes - Distance-checking uses an approximate 3x3x3 supercell method that can fail for highly distorted lattices, hence lattice angles are constrained to 30-150 degrees - Molecular distance checking (atom-atom by default) is the largest time cost and scales roughly with the square of molecule size; spherical approximation works poorly for non-spherical molecules like benzene - Without pre-symmetrization the ground state was not found at all in LJ benchmarks, but absolute hit counts are small (only 1 for LJ75) and may vary between runs - Molecular symmetry detection relies on Pymatgen's PointGroupAnalyzer; molecular flexibility is handled only via reorientation and dihedral perturbation, not general conformational sampling - Benchmarks are limited to elemental atomic systems (LJ clusters, C, Si); no molecular crystal CSP benchmark is reported despite the molecular Z' capability being a headline feature

Takeaways

- PyXtal is directly relevant as an alternative/complementary random structure generator to Genarris for molecular crystals, notably supporting arbitrary Z' including special Wyckoff positions - The molecular orientation enumeration algorithm (aligning molecular point group axes with Wyckoff site symmetry) is a concrete recipe for placing rigid molecules into special WPs, useful for Z'<1 and high-symmetry-molecule cases - Group-subgroup transition tooling offers a symmetry-aware way to generate related structures / perturbations, potentially useful as a GA mutation operator or for phase-transition studies - Empirical support that starting from symmetric structures improves low-energy structure discovery reinforces the rationale for symmetry-constrained generation in CSP - Practical open-source tool with ASE/Pymatgen interfaces and built-in PXRD similarity (correlation-based) for structure comparison

Relevance to GAtor 2.0

Moderately relevant to GAtor 2.0. PyXtal is a structure-generation tool in the same niche as Genarris, and its handling of molecules in special Wyckoff positions with arbitrary Z' is directly pertinent to the group's interest in Z'>1 and multi-component crystals. The orientation-enumeration algorithm and group-subgroup modulation could inform GA generation/mutation operators. However, the reported benchmarks are elemental atomic systems (LJ clusters, C, Si) with no molecular crystal CSP results, no dispersion-inclusive DFT ranking, and no GA/niching content, so its evidentiary value for molecular crystal ranking or finite-temperature stability is limited.
