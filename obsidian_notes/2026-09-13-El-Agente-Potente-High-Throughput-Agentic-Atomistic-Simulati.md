# El Agente Potente: High-Throughput Agentic Atomistic Simulations

**Authors:** [[Tsz Wai Ko]], [[Jiaru Bai]], [[Thomas Swanick]]
**Link:** https://arxiv.org/abs/2609.14840v1
**Scores:** relevance 70 / significance 0
**Field:** [[ML-potential]]

## Why it matters
An LLM-driven agentic framework combines typed, provenance-tracked execution graphs with a flexible coding mode to autonomously orchestrate MLIP-based high-throughput atomistic simulations across diverse materials/chemistry tasks.

## Abstract
> Foundational machine-learning interatomic potentials (MLIPs) are transforming atomistic simulations by achieving near-ab initio accuracy across large chemical spaces at a fraction of the computational cost. A central challenge in using these tools for high-throughput property calculations is translating high-level scientific intent into adaptive simulation campaigns without compromising workflow rigour. We introduce El Agente Potente, an agentic system that combines typed execution graphs with a complementary coding mode for MLIPs-driven atomistic simulations. Typed execution graphs provide structured and provenance-aware execution for standardized workflows, with large language models (LLMs) restricted to planning and routing while deterministic Python components perform scientific computation and validation. Complementing this structured execution, a coding agent constructs customized workflows for tasks requiring greater procedural flexibility while invoking existing Potente functions for supported calculations.
